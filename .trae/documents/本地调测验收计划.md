## Proposed Changes

### Part 1：sidecar 新增 xlsx 解析与脱敏支持

**1.1 `sidecar/requirements.txt`** — 追加
```
openpyxl          # XLSX 解析与写回（MIT）
```

**1.2 `sidecar/parsers.py`**
- `detect_format`：`if ext == ".xlsx": return "xlsx"`；`raise` 文案补充 XLSX。
- `parse_file`：`if fmt == "xlsx": return parse_xlsx(path, doc_id)`。
- 新增 `parse_xlsx(path, doc_id)`（仿 `parse_docx` 结构）：
  - lazy `import openpyxl`（保持空闲内存策略，`load_workbook(read_only=False)`，保留格式用于写回）；
  - 逐 worksheet（按 workbook.sheetnames 顺序）、逐行、逐列拼接文本：每 cell 文本追加后以分隔符拼接（非空 cell 间用 `\t`？——**统一用 `\n` 分隔每个 cell**，与其它格式的 span 协议一致，方便偏移映射）；sheet 之间插入 `\n`（与 PDF 页间一致）；
  - spans：`block=sheet 名`，`line=行号-1`，`page=0`，`bbox=None`；每个 cell 一个 span（`span_start/span_end` 基于全文偏移）；
  - structure：`{"sheet_count": N, "sheets": [{name, row_count, col_count}], "cell_count": K}`；
  - `ParseResult.docx_items` 复用字段放 `xlsx_cells`：`[(block, row_idx, col_idx, cell, cell_start, cell_text)]` 供 `redact_xlsx` 复用（不重复 load/遍历）；
  - 公式 cell：`cell.value` 以 `=` 开头且有 `data_type=="f"` → 记为 `structure["formula_cells"]`，解析时取其**缓存值**（`cell.value` 已是计算值或 None）——若为 None 跳过；解析本身不改写。

**1.3 `sidecar/redact.py`**
- `redact_file`（:547）增加 `elif fmt == "xlsx": return redact_xlsx(...)`。
- 新增 `redact_xlsx(input_path, replacements, output_path)`：
  - `load_workbook(input_path)`（保持公式/样式），逐 sheet 重放 `parse_xlsx` 的 cell 偏移表，把 replacements 按偏移归并到 cell（同一 cell 内多个替换按偏移排序、互不重叠——与 DOCX 段落同理）；
  - 应用：`cell.value = 新文本`（保留 number_format/字体/边框/合并状态）；公式 cell 命中 → 跳过 + warning「公式单元格未脱敏，请人工确认」；
  - 元数据清理：清空 core properties（`wb.properties` 的 author/title/subject/keywords/comments 置空，尽力而为）；
  - 返回与其它格式一致的 `{"is_deep": True, "replaced_count": N, "warnings": [...]}`；未映射的替换记入 warnings。

**1.4 `sidecar/tests/test_xlsx.py`**（新增）
- `make_xlsx(path)`：多 sheet（员工信息 sheet：姓名/身份证/手机/银行卡/住址/邮箱行；工资明细 sheet：金额/日期），含合并表头、加粗列、number_format；
- 用例：
  1. `parse_xlsx`：全文包含所有敏感串；span 偏移与全文一致；structure.sheet_count==2；公式 cell 不崩溃；
  2. `redact_xlsx` 全链路（POST /parse → 构造 replacements → POST /redact）：输出文件存在、原文件字节不变、`replaced_count` 正确、`is_deep==True`；
  3. 重开输出 xlsx：敏感原文零残留、掩码存在、number_format 保留、合并单元格保留、core properties 已清；
  4. 公式单元格命中 → 不崩溃、warning 输出、公式保留。

## Assumptions & Decisions

| 决策点 | 结论 |
|---|---|
| xlsx 依赖库 | openpyxl（MIT，permissive；能力覆盖读/写/样式/合并/公式读取） |
| xlsx 全文拼接分隔 | 每个 cell 一个 span，cell 之间与 sheet 之间均以 `\n` 分隔（与 DOCX/PDF 的 span 协议一致，偏移可落回） |
| 公式单元格 | 解析取缓存值；脱敏跳过公式 cell + warning「公式单元格未脱敏，请人工确认」 |
| xlsx 元数据 | openpyxl core properties 置空（尽力而为，与 DOCX 一致） |
| 模型 base_url 覆盖 | 环境变量 `ANK_MODEL_BASE_URL`（仅覆盖 base_url；未设置时行为与现在完全一致） |
| 测试文档集 | 提交进仓库 `testdocs/`（演示素材 + 回归样本）；敏感串必须过校验器（身份证校验位/Luhn） |
| 自测分工 | 我启动应用/起服务/程序化校验；用户目视 GUI 走查（用户已选） |
| 本次不发布 | 不做 .dmg 产物验收/真机双平台；PyInstaller xlsx 冒烟为可选项 |
